# Which witch are you?

A 13-question personality quiz that matches you to one of 19 types of witch. The questions are about your tastes and habits (photos, colours, weekends, weather), not about magic.

The witch types come from [19 Types of Witchcraft: Which Witch Are You?](https://themagickalpath.com/2022/08/07/19-types-of-witchcraft-which-witch-are-you/) on The Magickal Path. The descriptions in the quiz are my own short summaries.

## Run it

Open `index.html` in a browser. It's one file with no build step.
